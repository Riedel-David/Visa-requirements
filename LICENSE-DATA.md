## Attribution Requirements

If you use this data in your application or service, you must:

1. **Credit the source**: Attribute "Wikipedia contributors" as the original authors
2. **Link the source article**: Include a link to the relevant Wikipedia article (the `source_url` field in each passport file)
3. **Link the license**: Provide a link to CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/)
4. **Indicate changes**: State that the data was transformed and normalized from the original Wikipedia article format
5. **Share adaptations under the same license**: Any derivative works or adaptations of this data must be shared under CC BY-SA 4.0

## Attribution for Applications

If you display this data in an application (mobile app, website, etc.), you must show the attribution and disclaimer within the app in a visible location (e.g., About screen, data source section).

### Suggested Attribution String

```
Visa requirement data derived from Wikipedia (https://en.wikipedia.org),
licensed under CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/).
Data has been transformed and normalized. See source article: [link].

Visa data is community-sourced from Wikipedia and may be incomplete, outdated
or wrong. Always verify entry requirements with the official embassy or
government source of the destination before travelling.
```
