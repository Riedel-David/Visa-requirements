# Code of Conduct

This project follows the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Please read it at: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

This is a hobby project, so there are no guarantees about response times. Use GitHub's own tools: report abusive content to GitHub, or use the repository's private vulnerability reporting for anything that should not be public. No email address is published.
