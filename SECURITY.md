# Security Policy

This is a hobby project maintained by one person. There are no guarantees about response times or fixes.

## Reporting a Vulnerability

Please report security issues privately through GitHub's security advisory feature:

**[Report a vulnerability](https://github.com/Riedel-David/Visa-requirements/security/advisories/new)**

Please do not open a public issue for security vulnerabilities. I will try my best to look at reports, but it can take time to get a response.

## What to Report

Security issues may include:
- Code injection vulnerabilities in the pipeline
- Dependency vulnerabilities that affect the project
- Issues that could lead to malicious data injection
- Authentication or authorization bypasses in GitHub Actions workflows
