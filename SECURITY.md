# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately through GitHub's security advisory feature:

**[Report a vulnerability](https://github.com/Riedel-David/Visa-requirements/security/advisories/new)**

Please do not open a public issue for security vulnerabilities.

## What to Report

Security issues may include:
- Code injection vulnerabilities in the pipeline
- Dependency vulnerabilities that affect the project
- Issues that could lead to malicious data injection
- Authentication or authorization bypasses in GitHub Actions workflows

## Response Time

I will acknowledge your report within 48 hours and provide a more detailed response within 7 days, including next steps and expected timeline for a fix.

## Disclosure Policy

Please allow me reasonable time to address the vulnerability before any public disclosure.

Thank you for helping keep this project secure!
